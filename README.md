# eBPF / XDP 网络功能实验

本项目收集使用 **eBPF / XDP** 实现 **conntrack（连接跟踪）**、**firewall（防火墙）** 和 **forward（网络转发）** 的尝试，用于探索 Linux 网络数据路径中的状态维护、报文过滤和转发机制。

三个目录分别保留各自的实验代码、配置与资料，适合学习和验证实现思路。目前按独立实验组织，尚未作为统一的网络处理流水线进行集成验证，也不代表完整的生产级网络组件。

## 实验内容

### ct：连接跟踪

在 XDP 程序中解析报文，通过 BPF Map 保存和查找连接信息，探索双向流量的关联与连接状态维护。现有 Markdown 文档提供 network namespace、veth、地址及路由配置，以及 XDP 卸载和连接表清理示例。

### fw：防火墙

通过协议、源/目的 IP、源/目的端口等条件匹配规则，在 XDP 数据路径中决定放行或丢弃报文。用户态程序将规则组织为 bitmap，并通过 BPF Map 与内核态程序共享。

原有 PDF 包含环境准备、规则更新和查询接口、加载与挂载步骤、测试示例及设计说明；其中记录了 IPv6、分片报文和规则持久化等限制，复现实验时应结合当前源码核对。

### fwd：网络转发

按目的 IPv4 地址查询转发表，使用记录的出接口和 MAC 地址执行转发；源码也包含通过 `bpf_fib_lookup` 查询内核路由的路径，并使用 `bpf_redirect` 重定向报文。

原有 PDF 以多虚拟机拓扑记录路由、邻居表、XDP 挂载、抓包和连通性实验，可用于理解报文的转发过程。

## 代码组织与实验环境

各目录包含独立的 Go 模块与 CMake 构建配置：`bpf/` 存放 eBPF C 程序，`cmd/`、`pkg/` 等目录提供用户态代码，`conf/` 与 `deploy/` 保存配置和部署资料。

现有构建与实验资料使用 Linux 环境，涉及 Go、Clang/LLVM、CMake、BPF 相关头文件与库，以及 `bpftool`、`iproute2` 等工具。构建脚本包含 x86/amd64 与 Linux 头文件路径假设，其他架构需要适配。运行实验需要支持相应 eBPF/XDP 功能的内核和加载程序、配置网络所需的权限。

建议先阅读对应目录文档，再按实际环境调整网卡名、IP、路由与 BPF 挂载路径。文档中的发行版版本、依赖安装和测试结果是原有实验记录；本次目录整理未重新验证构建、兼容性或性能。

## 仓库与构建说明

`ct/`、`fw/`、`fwd/` 作为普通源码目录保留，不再包含各自的 `.git` 元数据。

现有 `CMakeLists.txt` 会调用 Git 获取 commit/tag。移除子目录 `.git` 后，原子仓库的版本信息不再可用；Git 也可能向上查找到外层仓库。再次构建前，需要明确版本信息来源并调整相关配置，尤其是 `fw` 的版本常量注入。本次整理保留原有构建脚本。
